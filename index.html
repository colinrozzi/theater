A supervised WebAssembly actor runtime

Theater

Run WebAssembly actors on your own machine — one binary, no cluster to stand up. Every message crossing the sandbox is recorded, so you can trace, replay, and debug exactly what happened. When an actor crashes, its supervisor restarts it clean instead of letting the failure spread.

$ curl -fsSL https://colinrozzi.github.io/theater/install.sh | sh

Linux x86_64 · one static binary · nothing else to install

Then create your first actor

$ theater --version
$ theater create hello

Your new project’s README walks it from build to first spawn.
